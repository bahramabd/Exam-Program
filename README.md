This repository contains a C#/.NET desktop application developed during an internship in 2023.

The project is a Windows Forms-based exam/course management application with SQL Server database integration. It includes form-based user interfaces for managing course-related data and performs database operations using ADO.NET.

## Features

- Windows Forms desktop interface
- Course and exam-related data management
- SQL Server database integration
- CRUD-style database operations
- DataGridView-based data display
- Form validation and exception handling
- Multi-form application structure

## Technologies

- C#
- .NET
- Windows Forms
- SQL Server
- ADO.NET
- Visual Studio
